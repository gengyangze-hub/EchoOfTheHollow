# 空谷回音 / Echoes of the Hollow

一个星露谷物语 SMAPI 模组，将鹈鹕镇改造为没有金钱、技能等级、成就和好感度的世界。取而代之的是 **多棱镜日志系统**——每个 NPC 用自己独特的视角和语言风格记录关于你的主观记忆片段。

## 核心理念

- 📔 **没有数字评判** — 移除金币、技能、好感度心形、成就
- 🪶 **多棱镜日志** — NPC以第一人称写下关于你的记忆
- 🧺 **互惠篮** — 替代经济系统的礼物交换
- 🌊 **漂流物箱** — 替代出货箱的"放生"机制
- 🌿 **兴致系统** — 替代体力值的活动多样性追踪
- 💌 **邀约留言柱** — 替代任务板的休闲邀约
- 🎐 **节日重制** — 4个传统节日回归简单共处
- 💤 **离线记忆** — 现实时间流逝后生成的"你不在时"的记忆
- 🌬️ **新活动** — 发呆、听风、触摸旧物、追踪动物

## 安装

1. 安装 [SMAPI](https://smapi.io) 4.0+
2. 将 `EchoesOfTheHollow` 文件夹放入 `Stardew Valley/Mods/`
3. 启动游戏

## 🔑 记忆后门

在 `assets/data/templates/` 目录下放任何 `.json` 文件来添加新记忆模板，**无需重新编译模组**。

详见 [`assets/data/templates/README.md`](assets/data/templates/README.md)

## 配置

通过 Generic Mod Config Menu 或直接编辑 `config.json` 可开关所有子系统。

## 存档安全

模组只运行时拦截数值，**不修改存档中的实际数据**。移除模组后金钱和好感度原样恢复。

## 开发

```bash
dotnet build -c Release
```
